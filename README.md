# 🧠 Creative Rule Engines

This repository is the **canonical source of truth** for all creative standards across Cursor projects.

## 🎯 What This Is

A collection of interconnected **excellence engines** that enforce quality standards for:

- 🎼 **Music Composition** — Orchestral, jazz big band, hybrid chamber, guitar trio, songwriting
- ✍️ **Literature** — Short stories, novels, poetry, editing
- 🧠 **Therapy Writing** — EMDR documentation, psychoeducation, clinical templates

Each engine defines **criteria of excellence**, **workflows**, **templates**, and **quality thresholds** to ensure outputs reach professional/artist-level quality (target: 9/10).

### Option 1: Import the Master File (Recommended)

Add `cursor-system-pack.md` as your system prompt or project rules in Cursor:


Then specify your mode:
- `"Mode: Big Band"`
- `"Mode: Orchestral"`

## 🎼 Music System

### Criteria of Excellence (0-10)

| Score | Level | Description |
|-------|-------|-------------|
| 0–2 | Broken | No structure, tonality, or form |
| 3–4 | Rough Sketch | Underdeveloped ideas |
| 5–6 | Functional | Coherent but generic |
| 7 | Good Student | Clear motifs, workable form |
| 8 | Emerging Pro | Real structure, ready to refine |
| **9** | **Artist-Level** | **Target — Performance-ready** |
| 10 | Mastery | Major composer level |

### Core Rules (Non-Negotiable)

1. **Motivic Development** — Define 1–3 motifs, recur every 4–8 bars
2. **Form & Length** — Lead sheets ≥24–32 bars, movements ≥32 bars
3. **Harmony** — Use Tonality Vault (melodic triads, quadratonics, tension layers)
4. **Idiomatic Writing** — Guitar drop-2/3, winds breathing, strings bowings
5. **Orchestration** — Know who has the line, avoid muddy textures
6. **Engraving** — Sibelius-friendly MusicXML, correct durations

### Tonality Vault

The harmonic framework built on:
- **Melodic Triad** — Gravitational centre for strong beats
- **Quadratonics** — Triad + 1 tension for voicings
- **Tension Triads** — Dramatic colour
- **Layered Tension System** — L1 (safe) → L2 (urgent) → L3 (chromatic)
- **Harmonic Hierarchy** — 3 → 7 → 5 → 9 → 11 → 13 → Root

## 🔢 Versioning Rules

All creative work follows this lifecycle:

| Version | Stage |
|---------|-------|
| v0.x | Exploration — Rough sketches, tests |
| v1.x | Structure — Form, motif, harmonic map |
| v2.x | Harmony — Colour choices, Tonality Vault |
| v3.x | Melody & Motif — Phrase shaping, clarity |
| v4.x | Accompaniment — Bass, inner voices |
| v5.x | Orchestration — Parts, colours, dynamics |
| v6.x | Engraving — Spacing, articulations |
| v7.x | Polish — Humanising, breath, arcs |
| v8.x | Performance-Ready — Meets all criteria |
| v9.x | Final Artistic — Expression, nuance |
| v10.x | Release — Published/performed |

## 🔥 Quality Enforcement

The system automatically enforces:

- ✅ Minimum 7/10 per axis, prefer 8–9/10
- ✅ Motivic recurrence every 4–8 bars
- ✅ Harmonic depth via Tonality Vault
- ✅ Engraving correctness for .musicxml
- ❌ No generic patterns or robotic lines
- ❌ No filler bars or underdeveloped movements
- ❌ No "AI smell" in creative work

## 📋 MusicXML Duration Reference

**Formula:** `MEASURE_DURATION = (BEATS × DIVISIONS × 4) / BEAT_TYPE`

With divisions=256:

| Time Sig | Duration |
|----------|----------|
| 4/4 | 1024 |
| 3/4 | 768 |
| 6/8 | 768 |
| 9/8 | 1152 |
| 7/8 | 896 |
| 12/8 | 1536 |

**Note values:** Whole=1024, Half=512, Quarter=256, Eighth=128, Sixteenth=64
