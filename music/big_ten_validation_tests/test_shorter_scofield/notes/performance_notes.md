# Performance Notes: Narrative Drift

## Style Feel

Shorter-style narrative form with Scofield groove lift. Medium groove, ♩ = 132. C minor, AABA.

## Rehearsal Suggestions

- Establish the groove before the head; the eighth-note motif (Eb–G–Bb–D–Eb) sets the tone.
- Rehearse A and A2 together—the phrase accents at bar 8 and bar 12 should feel like natural phrase endings.
- Run the bridge (B) separately to lock in the brighter harmonic colour (Dbmaj7, Ab7, Ebmaj7#11, Ab7).
- At A3, cue “lay back” so the return feels relaxed, not rushed.

## What the Band Should Listen For

- The recurring motif as a narrative anchor; each return should feel like a scene reprise.
- Groove lift on the syncopated phrase endings (bars 4, 8, 12, 20).
- The bridge as a distinct scene shift—brighter, more open—before returning to the main groove.

## Where the Bridge Changes Character

**Bars 13–16 (B):** The bridge introduces Dbmaj7 and moves through Ab7, Ebmaj7#11, Ab7. Harmonic colour shifts from minor narrative to a brighter, more open feel. The chart marks this as “Bridge — scene shift · brighter colour.” At bar 17 (A3), the cue “Back to groove · lay back” signals the return to the main narrative feel.
