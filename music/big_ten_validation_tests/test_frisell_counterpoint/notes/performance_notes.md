# Performance Notes: Quiet Orbit

## Style Feel

Frisell atmosphere with spacious contrapuntal motion. Sustained, more open, breathe. ♩ = 44. D major, AABA. Guitar + string quartet.

## Rehearsal Suggestions

- Prioritise space and sustain over density. Let whole notes and rests breathe.
- The wide intervallic spacing (B4–D6) suggests counterpoint; allow the lines to float.
- Rehearse the bridge (B) separately—Gbmaj7, Cbmaj7, Fmaj7, Am9 introduce a floating tonal colour.
- At A3, cue “Back to spacious feel” so the return is calm and spacious.

## What the Band Should Listen For

- Sustained tones and rests as part of the contrapuntal texture.
- The bridge’s new harmonic colour (Gbmaj7, Cbmaj7) as a distinct, floating section.
- Wide intervallic spacing (B4–D6) as a defining feature of the Frisell atmosphere.

## Where the Bridge Changes Character

**Bars 13–16 (B):** The bridge introduces Gbmaj7, Cbmaj7, Fmaj7, Am9. Harmonic colour shifts from D major to a floating, more open palette. The chart marks this as “Bridge — floating colour · more sustained.” At bar 17 (A3), the cue “Back to spacious feel” signals the return to the main atmosphere.
