# Scofield–Holland Groove Engine

## Core Priorities

- **Groove** — Rhythmic lift, forward motion, never static
- **Dyadic guitar voicings** — Two-note comping, rhythmic displacement
- **Bass movement** — Walking or ostinato, active harmonic support
- **Rhythm-section sensibility** — Syncopated comping, guitar as harmonic and rhythmic colour

## Characteristics

- Medium-to-up tempo
- Chord symbols favour altered dominants and blues-inflected harmony
- Guitar in dyadic/triadic comping role
- Bass with active movement
- Optional drums/percussion

## Avoid

- Static harmony
- Block chords
- Overly dense voicings
- Loss of rhythmic lift
