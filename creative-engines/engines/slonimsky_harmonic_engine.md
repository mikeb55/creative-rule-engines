# Slonimsky Harmonic Engine

## Core Priorities

- **Thesaurus-derived** — Interval cycles, symmetrical structures
- **Systematic exploration** — IC1–IC6, axis-based harmony
- **Non-functional logic** — Fortspinnung, development by interval
- **Modern colour** — Polychords, tension triads

## Characteristics

- Interval cycles (IC1–IC6)
- Axis-based harmonic planning
- Symmetrical structures
- Polychord stacks
- German Development / Fortspinnung movements

## Avoid

- Purely functional harmony
- Random chromaticism
- Loss of systematic logic
- Over-familiar progressions
