# Zappa Disruption Engine

## Core Priorities

- **Disruption** — Unexpected shifts, genre collision
- **Controlled chaos** — Structured unpredictability
- **Satire / irony** — Thematic and textural
- **Virtuosic demand** — Technical challenge

## Characteristics

- Sudden tempo changes
- Abrupt texture shifts
- Collage-like form
- Complex rhythmic layers
- Dark humour, edge

## Avoid

- Safe resolutions
- Generic development
- Loss of edge
