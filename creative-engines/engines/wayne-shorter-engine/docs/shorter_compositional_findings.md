# Wayne Shorter Compositional Findings

**Purpose:** Extract actionable rules and principles for the Wayne Shorter Engine.

---

## 1. Melodic Construction

### Interval Preference

- **Primary:** Minor 3rd, tritone, perfect 4th, minor 2nd
- **Secondary:** Major 2nd, major 3rd
- **Avoid:** Predictable scalar runs; arpeggiated chord tones in sequence

### Motivic Logic

- Themes built from 3–6 note cells
- Cells developed through: repeat, invert, transpose, fragment, extend, interrupt
- Development occurs within phrase, not only across sections
- Rest and silence are motivic elements

### Contour

- Angular: leaps (4th, 5th, tritone) followed by stepwise recovery
- Lyrical: sustained notes; legato phrasing
- Asymmetric: phrase lengths that avoid 4+4 default

---

## 2. Harmonic Language

### Non-Functional Harmony

- Root movement by: minor 3rd, major 3rd, perfect 4th, tritone, half-step
- Avoid: predictable ii–V–I; dominant-tonic resolution as default
- Resolution may occur through: register change, density release, motivic return

### Chromatic Planing

- Parallel structures moving by half-step: Cm7 → C♯m7 → Dm7
- Whole-step planing: Cm7 → Dm7 → Em7
- Planing as structural, not decorative

### Modal Foundations

- Dorian, Phrygian, Lydian, Mixolydian
- Modal interchange without clear tonic
- Multiple centers implied simultaneously

### Chord Extensions

- 9ths, #11s, ♭5s as structural
- Sus chords; add9; minor 9
- Cluster voicings at tension points

---

## 3. Phrase Asymmetry

### Allowed Phrase Lengths

- 3+5, 5+4, 4+4+3, 7+5, 3+3+2, 6+6, 5+7, 4+3+4
- Irregular: 3+4+5, 5+3+4, etc.
- Reject: extended 4+4+4+4 without variation

### Phrase Boundary Behavior

- Delayed cadence: phrase extends past expected end
- Early cadence: phrase truncates
- Overlap: next phrase begins before previous ends
- Restart: motif restarts mid-phrase

---

## 4. Form Behavior

### Short Forms

- 8–16 bar themes
- 12-bar blues with chromatic turnaround
- AABA with altered bridge (e.g., 8+8+8+8 with harmonic surprise in bridge)

### Modular Phrase Chains

- Phrases link without literal repetition
- Each phrase derives from shared motivic source
- Narrative arc: build, release, suspend

### Through-Composed Feel

- Few literal repeats
- Sections evolve rather than return
- Form emerges from motivic development

---

## 5. Motivic Transformation

### Transformation Types

| Type | Description | Example |
|------|-------------|---------|
| Repeat | Exact or near-exact | [C Eb G] → [C Eb G] |
| Invert | Mirror | [C Eb G] → [G Eb C] |
| Transpose | Shift by interval | [C Eb G] → [F Ab C] |
| Fragment | Subset | [C Eb G A] → [C Eb G] |
| Extend | Add notes | [C Eb G] → [C Eb G Bb] |
| Interrupt | Cut off; restart | [C Eb G] — [G Bb D] |

### Transformation Rules

- At least one transformation per phrase
- Avoid literal repetition for more than 2 consecutive statements
- Transposition often by minor 3rd, tritone, or 4th

---

## 6. Chromatic Root Movement

### Allowed Root Progressions

- Down by half-step: C → B
- Up by half-step: C → C♯
- Down by whole-step: C → Bb
- By minor 3rd: C → A, C → Eb
- By tritone: C → F♯
- By perfect 4th: C → F, C → G

### Turnaround Logic (Footprints-style)

- Mask blues structure with chromatic movement
- Example: F♯m9(♭5) → F7(♯11) → E9(♭5) → A7(♯9) → Cm7
- Doubled harmonic rhythm; non-standard voicings

---

## 7. Tonal Ambiguity

### Techniques

- Multiple possible roots; listener suspended
- Pedal bass with shifting harmony above
- Modal interchange without clear tonic
- Pitch centricity without functional tonality

### Validation

- Output should not resolve to obvious tonic too often
- Harmonic motion should feel exploratory, not conclusive

---

## 8. Ensemble Interaction

### Role Types

- Melody (lead)
- Counterline (derived from motif)
- Harmonic color (voicings, clusters)
- Rhythmic punctuation (accents, hits)
- Bass (pedal, motivic, or walking)

### Equality Principle

- No instrument purely accompaniment
- All parts derive from shared structural material
- Melody may pass between instruments

---

## 9. Rhythmic Placement

### Cross-Rhythm

- Tresillo (3+3+2) in bass
- 3-over-2 feel
- Metric ambiguity (6/4 vs 3/4 vs 4/4)

### Phrase Rhythm

- Motifs may enter on off-beats
- Delayed entry; early exit
- Syncopation as structural, not decorative

### Convergence

- Rhythmic layers should periodically align
- Avoid continuous displacement without anchor

---

## 10. GCE (Generic Jazz Cliché Exclusion)

### Target: GCE ≥ 9.0

Outputs must:

- Exhibit motivic continuity
- Maintain harmonic ambiguity
- Preserve phrase asymmetry
- Uphold interval logic consistency
- Show harmonic color diversity

### Reject If

- Resembles generic jazz language
- Predictable ii–V–I sequences
- Symmetric 4-bar phrases throughout
- Scalar bebop lines
- Clichéd turnarounds
