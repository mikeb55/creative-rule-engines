# Andrew Hill Engine Rule Modules

## Module 1 — Ambiguous Field Generator

Generates harmonic regions using interval cells.

**Output:**

- pitch field
- color tension
- register target

Avoid fixed tonal centers.

---

## Module 2 — Stammer Motif Transformer

Transforms motifs using interruption and restart patterns.

**Allowed operations:**

- repeat fragment
- truncate
- restart
- rhythmic displacement

---

## Module 3 — Phrase Asymmetry Engine

Constructs phrase groups such as:

- 3+5
- 5+4
- 4+4+3

Reject endless 4+4 phrase repetition.

---

## Module 4 — Rhythmic Layer Engine

Creates simultaneous rhythmic strata:

- pulse layer
- displacement layer
- phrase-stretch layer

Ensure periodic convergence points.

---

## Module 5 — Ensemble Equality Engine

Ensures parts derive from shared motif/harmonic structures.

No voice may remain purely accompanimental.
