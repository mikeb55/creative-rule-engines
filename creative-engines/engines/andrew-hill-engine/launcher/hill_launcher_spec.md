# Andrew Hill Engine Launcher (V4.0)

**Purpose:** Provide a simple entry point to run the Hill engine runtime generator.

---

## Launcher Behavior

1. Call the runtime generator.
2. Generate a Hill phrase.
3. Validate the phrase.
4. Export MusicXML.
5. Write file to outputs directory.

---

## Expected Output Location

```
creative-engines/engines/andrew-hill-engine/outputs/
```

---

## File Naming Convention

```
hill_phrase_YYYY_MM_DD_HHMM.musicxml
```

Example: `hill_phrase_2026_03_14_0715.musicxml`
