# Hill vs Monk/Harris Comparison Test

## Purpose

Ensure the Hill engine produces behavior distinct from Monk/Harris.

## Compare Across

- phrase symmetry
- harmonic function
- rhythmic behavior
- ensemble interaction
- motivic treatment

## Hill Should Show

- more ambiguity
- more asymmetry
- more layered rhythmic behavior
- less functional harmonic pull
- less melody/accompaniment hierarchy

## Monk/Harris Should Show

- stronger tonal gravity
- clearer punctuation or shell logic
- more explicit harmonic identity
- less field-based ambiguity

## Fail Condition

Fail the comparison if Hill output could be mistaken for generic Monk/Harris output.
