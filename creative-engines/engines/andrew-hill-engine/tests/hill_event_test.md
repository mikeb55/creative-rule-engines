# Hill Event Test

## Test Goal

Verify that Hill engine output can be represented as structured event data before notation/export.

## Test Steps

1. choose one interval cell
2. choose one harmonic field
3. choose one phrase type
4. choose rhythmic displacement pattern
5. construct 8-bar event sequence
6. validate using hill_validation_checklist.md

## Expected Outcome

A valid Hill event sequence must:

- show asymmetrical phrase grouping
- preserve interval-cell logic
- avoid tonal cadence
- maintain ensemble equality
- contain at least one rhythmic convergence point
