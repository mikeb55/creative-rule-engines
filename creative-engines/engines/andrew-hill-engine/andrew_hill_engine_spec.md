# Andrew Hill Engine — V1.0

**Category:** Composition Grammar Engine

## Purpose

Model Andrew Hill's compositional language as a system of controlled ambiguity built on interval cells, asymmetrical phrase structures, independent ensemble lines, and layered rhythmic perception.

The engine must not generate free jazz randomness.  
It must generate structured ambiguity that retains musical momentum.

---

## CORE MUSICAL IDENTITY

Andrew Hill music combines:

- interval-cell construction
- harmonic ambiguity
- asymmetrical phrase grouping
- layered rhythmic strata
- equal-status ensemble voices
- dark tonal color

The engine must preserve formal signposts while destabilizing internal phrase behavior.

---

## CORE RULES

### 1. FORM WITH DESTABILIZED INTERIOR

Sections must exist, but phrase behavior may vary.

**Allowed structures:**

- 3+5 phrases
- 5+4 phrases
- 4+4+3 phrases
- offset cadences

Reject engines that generate endless symmetric phrases.

---

### 2. AMBIGUOUS HARMONIC FIELDS

Harmony must not default to functional progressions.

**Allowed behaviors:**

- interval-cell sonorities
- color-based harmonic motion
- recurring tonal shadows
- suspended resolution

Avoid routine ii–V–I movement.

**Resolution may occur through:**

- register change
- density release
- motivic return

---

### 3. STAMMER MOTIF GENERATION

Motifs may:

- repeat fragments
- restart mid-phrase
- truncate endings
- shift rhythmic placement

**Motif transformation grammar:**

- repeat
- compress
- interrupt
- restart
- extend

---

### 4. ANGULAR BUT MEMORABLE THEMES

Themes should combine:

- intervallic leaps
- contour recurrence
- irregular phrase rhythm

Reject themes that behave like scalar bebop lines.

---

### 5. LAYERED RHYTHMIC STRATA

The engine must support multiple simultaneous rhythmic layers.

**Example behavior:**

- pulse layer
- displacement layer
- phrase-stretch layer

The system must periodically converge rhythmically to maintain direction.

---

### 6. EQUAL-STATUS ENSEMBLE LINES

No instrument should function as passive accompaniment.

All parts derive from shared structural material.

**Possible roles:**

- melody
- counterline
- harmonic color
- rhythmic punctuation

---

### 7. DARK REGISTRAL COLOR

Favor darker instrumental ranges.

**Preferred textures:**

- middle-low register voicings
- bass clarinet colors
- dense interior registers

Avoid overly bright ensemble balance.

---

### 8. CLUSTER PRESSURE EVENTS

Close interval clusters may appear as tension points.

Clusters must function as:

- pivot events
- structural pressure points
- phrase boundary markers

Clusters must not dominate the texture.

---

## OUTPUT TYPES

The engine produces:

- motif studies
- harmonic sketches
- ensemble fragments
- short themes
- counterline networks

The engine should not attempt full compositions in early versions.

---

## VALIDATION RULES

Reject output if:

- harmony resolves conventionally too often
- phrases remain symmetrical for extended passages
- ensemble roles collapse into melody + accompaniment
- clusters appear continuously without contrast
- angular melodies lack recurrence
- rhythmic freedom removes forward motion
