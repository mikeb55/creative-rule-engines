# Polyphonic Labyrinth Engine

## Core Priorities

- **Dense but clear polyphony** — Multiple independent voices
- **Inner motion** — Each voice has its own logic
- **Labyrinthine form** — Non-linear, winding structure
- **Textural alternatives** — Voicing and divisi choices

## Characteristics

- Multiple independent voices
- Dense texture with clarity
- Labyrinthine or non-linear form
- Alternate divisi logic
- Contrast between dense and lean passages

## Avoid

- Simplification that destroys polyphony
- Block harmony
- Loss of inner motion
- Muddy textures
