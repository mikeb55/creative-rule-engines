# The Mighty Ten Engines — User Guide V2

## Overview

The **Mighty Ten** is a global 10-engine composition framework. This guide provides an extended reference: engine comparison matrix, album placement, hybrid combinations, Cursor prompts, and orchestration tips.

## GCE ≥ 9 Rule (Non-Negotiable)

**Before any MusicXML output:** Ensure the composition scores **≥ 9/10** on the Global Criteria of Excellence across all axes. If any axis is under 7, run another revision pass. Iterate until artist-level (9) before export.

## When to Use Each Engine on an Album

### Opener / High-Energy
- **Scofield–Holland** — Groove-based, rhythm-section forward. Best for track 1 or live opener.
- **Stravinsky Pulse** — Rhythmic drive, orchestral. Strong for album opener or climax.

### Lyrical / Accessible
- **Wheeler Lyric** — Singable melody, warmth. Best for singles, radio, or emotional centre.
- **Counterpoint Hybrid** — Chamber lyric gravity. Good for intimate tracks.

### Atmospheric / Contrast
- **Frisell Atmosphere** — Space and restraint. Use after dense tracks for breath.
- **Bartók Night** — Dark, folk-inflected. Use for mood contrast.

### Structural / Narrative
- **Shorter Narrative** — Motivic storytelling. Use for pieces with clear sectional logic.
- **Polyphonic Labyrinth** — Dense polyphony. Use sparingly (1–2 per album); delicate.

### Edge / Disruption
- **Zappa Disruption** — Controlled chaos. Use 0–1 per album for contrast.
- **Slonimsky Harmonic** — Systematic harmony. Use for modern colour.

### Album Balance Guidelines
- **Groove:** 1–2 pieces (Scofield)
- **Narrative:** 1–2 pieces (Shorter)
- **Atmospheric:** 1–2 pieces (Frisell, epilogue-style)
- **Lyrical:** 1–2 pieces (Wheeler, Counterpoint)
- **Rhythmic:** 0–1 pieces (Stravinsky)
- **Disruptive:** 0–1 pieces (Zappa)
- **Harmonic:** 0–1 pieces (Slonimsky)
- **Dark:** 0–1 pieces (Bartók)
- **Polyphonic:** 1–2 pieces (Counterpoint, Polyphonic Labyrinth)

## Orchestration Tips per Engine

### Scofield–Holland
- Guitar: dyadic voicings, drop-2/3, rhythmic displacement
- Bass: walking or ostinato, active movement
- Drums/percussion: light kit, open feel; optional
- Avoid: block chords, static harmony, dense voicings

### Shorter Narrative
- Clear sectional divisions; varied textures per section
- Motivic cells in intro, interludes, transitions
- Endings: offer closed and open options
- Avoid: fixed forms, predictable grooves

### Frisell Atmosphere
- Guitar: dyads only in sparse passages; avoid full triads
- Strings: long-held pads, harmonics, divisi
- Space between attacks; slow tempo
- Avoid: rhythmic fills, density, over-complication

### Wheeler Lyric
- Flugelhorn/brass for lyrical statements
- Warm voicings; protect the melody
- Harmonic surprise: bII, bVI, unexpected modulations
- Avoid: over-complication, cold voicings

### Stravinsky Pulse
- Ostinato-based development; metric displacement
- Block scoring; timbral contrast
- Strong rhythmic identity; irregular phrase lengths
- Avoid: static metre, predictable phrase lengths

### Zappa Disruption
- Sudden tempo changes; abrupt texture shifts
- Collage-like form; complex rhythmic layers
- Virtuosic demand; edge and satire
- Avoid: predictable flow, safe resolutions

### Slonimsky Harmonic
- Interval cycles (IC1–IC6); axis-based planning
- Polychord stacks; symmetrical structures
- Fortspinnung-type development
- Avoid: purely functional harmony, random chromaticism

### Bartók Night
- Polymodal; quartal/quintal voicings
- Asymmetric rhythms; folk-inflected
- Chamber density; clear but rich
- Avoid: over-resolution, generic minor

### Counterpoint Hybrid
- Two-line or multi-line logic; no block harmony
- Guitar + strings or guitar duo
- Independence of voices; chamber voicings
- Avoid: doubling that obscures independence

### Polyphonic Labyrinth
- Multiple independent voices; dense but clear
- Alternate divisi logic; inner motion
- Contrast dense vs lean passages
- Avoid: simplification that destroys polyphony
