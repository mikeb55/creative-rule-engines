# Engine Master Palette

The **Mighty Ten** — global 10-engine composition framework.

## Engine Overview

| Engine | Core Priorities | Best For |
|--------|-----------------|----------|
| **Scofield-Holland** | Groove, dyadic guitar, bass movement | Rhythm-section, medium-up tempo |
| **Shorter Narrative** | Motivic storytelling, sectional logic | Structural variation, narrative pacing |
| **Frisell Atmosphere** | Space, colour, restraint | Sparse, atmospheric, slow |
| **Wheeler Lyric** | Melody, warmth, harmonic surprise | Lyrical, singable, warm |
| **Stravinsky Pulse** | Pulse, ostinato, metric irregularity | Rhythmic drive, orchestral |
| **Zappa Disruption** | Disruption, controlled chaos | Edge, satire, virtuosity |
| **Slonimsky Harmonic** | Interval cycles, systematic exploration | Modern colour, non-functional |
| **Bartók Night** | Night textures, polymodal, darkness | Chamber, folk-inflected |
| **Counterpoint Hybrid** | Chamber voicings, counterpoint | Two-line logic, lyric gravity |
| **Polyphonic Labyrinth** | Dense polyphony, inner motion | Labyrinthine form, multi-voice |

## Selection Guide

- **Groove-based:** Scofield-Holland
- **Narrative / structural:** Shorter Narrative
- **Atmospheric / sparse:** Frisell Atmosphere
- **Lyrical / warm:** Wheeler Lyric
- **Rhythmic / orchestral:** Stravinsky Pulse
- **Disruptive / edgy:** Zappa Disruption
- **Systematic harmony:** Slonimsky Harmonic
- **Dark / folk:** Bartók Night
- **Contrapuntal:** Counterpoint Hybrid
- **Dense polyphony:** Polyphonic Labyrinth
