# Composition Structure Rules

## Form & Length

- Lead sheets: ≥ 24–32 bars minimum
- Movements: ≥ 32 bars
- Suites: multiple movements, each with full motivic development

## Motivic Development (Non-Negotiable)

- Define 1–3 motifs at start
- Recur every 4–8 bars
- Use transformations: inversion, sequence, augmentation, diminution, retrograde, fragmentation

## Sectional Logic

- Clear sectional divisions (A, B, bridge, etc.)
- Each section has a purpose
- Transitions between sections are deliberate

## Harmonic Planning

- Use Tonality Vault (melodic triads, quadratonics, tension layers)
- Hierarchy: 3 → 7 → 5 → 9 → 11 → 13 → Root
- Plan harmonic arc across full piece
