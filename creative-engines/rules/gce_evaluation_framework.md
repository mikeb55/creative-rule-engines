# GCE Evaluation Framework

Global Criteria of Excellence (GCE) for composition quality assessment.

## Scoring Bands (0–10)

| Score | Level | Description |
|-------|-------|-------------|
| 0–2 | Broken | No structure, tonality, or form |
| 3–4 | Rough Sketch | Underdeveloped ideas |
| 5–6 | Functional | Coherent but generic |
| 7 | Good Student | Clear motifs, workable form |
| 8 | Emerging Pro | Real structure, ready to refine |
| **9** | **Artist-Level** | **Target — Performance-ready** |
| 10 | Mastery | Major composer level |

## Core Dimensions

1. Motivic Identity & Development
2. Melodic Line (contour, singability, character)
3. Harmonic Language (colour, logic, depth)
4. Formal Shape (length, proportion, pacing)
5. Rhythm & Feel (human, expressive)
6. Texture & Orchestration Consciousness
7. Idiomatic Writing (instrument-specific)
8. Engraving & Clarity (for performers)
9. Emotional / Narrative Arc
10. Afterglow (memorability)

## Usage

- Target: minimum 7/10 per axis, prefer 8–9/10
- If any axis is under 7, the piece needs another pass
- See `../../music/excellence-criteria.md` for full criteria
